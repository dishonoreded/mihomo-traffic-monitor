# Triage Labels

These canonical roles map directly to GitHub label names in this repository.

| Role | Label | Meaning |
| --- | --- | --- |
| Category | `bug` | Something is not working |
| Category | `enhancement` | New feature or request |
| Triage | `needs-triage` | Maintainer evaluation is required |
| Triage | `needs-info` | Waiting for more information |
| Triage | `ready-for-agent` | Fully specified and ready for an agent |
| Triage | `ready-for-human` | Requires human implementation |
| Triage | `wontfix` | Will not be actioned |
| Wayfinder | `wayfinder:map` | Map for a large, foggy effort |
| Wayfinder | `wayfinder:research` | Primary-source research decision ticket |
| Wayfinder | `wayfinder:prototype` | Runnable prototype decision ticket |
| Wayfinder | `wayfinder:grilling` | Human-in-the-loop decision ticket |
| Wayfinder | `wayfinder:task` | Task that unblocks a decision |

When a skill mentions a canonical role, use the corresponding label exactly.
Existing labels are authoritative and must not be silently edited or deleted.
